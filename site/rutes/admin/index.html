    Rutes: Backoffice (/admin)¶

    Mapa complet del panell d'administració. Accés: ROLE_ADMIN per a tot /admin, excepte ^/admin/gestions que accepta ROLE_GESTOR (jerarquia: ROLE_GESTOR implica ROLE_USER; ROLE_ADMIN implica tots dos). Vegeu Rols i control d'accés.

    Font: bin/console debug:router (nucli del 17/11/2026). 30 rutes en aquest fitxer. Perfil d'ús: el Backoffice és una cabina d'alta densitat dissenyada per a escriptori; a mòbil adopta un mode compacte de seguiment (KPIs essencials i comprovació de serveis) amb advertència de gestionar les tasques denses a PC (vegeu AGENTS.md).

    Dashboard i API interna¶

    Ruta Path Mètode Controlador Descripció
    app_admin_dashboard /admin ANY Admin\AdminDashboardController::index Tauler de KPIs: usuaris, béns, certificats, ingressos, cues actives.
    app_admin_api_geo /admin/api/geo GET Admin\AdminDashboardController::apiGeo Resol l'IP de l'administrador contra la BD GeoIP local (indicador de geolocalització al capçalera).

    Usuaris (AdminUserController) — 3 rutes¶

    Ruta Path Mètode Descripció
    app_admin_users /admin/usuaris ANY Llista i cerca d'usuaris (filtres per pla, estat, proveïdor).
    app_admin_user_detail /admin/usuaris/{id} GET Fitxa de l'usuari: dades, pla, béns, certificats, activitat.
    app_admin_user_toggle_status /admin/usuaris/{id}/toggle-status POST Activa/desactiva el compte (amb motiu de bloqueig visible a l'usuari; vegeu UserChecker).

    Béns (AdminItemController) — 3 rutes¶

    Ruta Path Mètode Descripció
    app_admin_items /admin/bens GET Llista de béns de tots els usuaris (CUI, estat, pla, versió).
    app_admin_item_show /admin/bens/{cui} GET Fitxa administrativa del bé (fingerprint SHA-256, històric, ancoratges).
    app_admin_item_update_status /admin/bens/{cui}/estat POST Canvia l'estat del bé (administratiu: frozen, needs_review, etc. — fora de la màquina d'estats; vegeu Cues i asíncronicitat → Màquina d'estats).

    Plans (AdminPlanController) — 3 rutes¶

    Ruta Path Mètode Descripció
    app_admin_plans /admin/plans ANY Llista de plans (Free, Plus, Unlimited) amb quotes en viu.
    app_admin_plan_edit /admin/plans/{id}/edit GET,POST Edició de quotes en calent: maxActiveItems, maxYearlyRegistrations, fotos, evidències, consultes IA (vegeu AGENTS.md → Parametrització en calent).
    app_admin_plan_toggle_ai /admin/plans/{id}/toggle-ai POST Activa/desactiva l'assistència IA per pla (feature toggle per pla, complementari al global AI_ASSISTANCE_ENABLED).

    El Pla Unlimited es manté is_active = false (bloquejat per a contractació) amb distintiu «Properament» al MVP.

    Factures (AdminInvoiceController) — 4 rutes¶

    Ruta Path Mètode Descripció
    app_admin_invoices /admin/factures GET Llista de factures (estat, import, usuari, concepte).
    app_admin_invoices_export_csv /admin/factures/exportar GET Exporta la llista filtrada a CSV (comptabilitat).
    app_admin_invoice_pdf /admin/factures/{uuid}/pdf GET Descarrega el PDF d'una factura.
    app_admin_invoice_refund POST /admin/factures/{uuid}/reemborsar POST Processa un reemborsament (registra REFUND_PROCESSED a l'auditoria).

    Gestions d'herència (AdminSuccessionClaimController, ROLE_GESTOR) — 6 rutes¶

    Ruta Path Mètode Descripció
    app_admin_gestions_herencies /admin/gestions/herencies GET Safata d'expedients successororis (estat, titular, llegatari, urgència).
    app_admin_gestions_herencia_show /admin/gestions/herencies/{uuid} GET Fitxa de l'expedient: documents, pre-aval IA, històric.
    app_admin_gestions_herencia_document /admin/gestions/herencies/{uuid}/document/{kind} GET Lliurament d'un document de l'expedient (kind = tipus documental).
    app_admin_gestions_herencia_retriatge /admin/gestions/herencies/{uuid}/ai-retriatge POST Dispara el retriatge OCR local (AnalyzeSuccessionClaimMessage → cua async_ai) per al pre-aval.
    app_admin_gestions_herencia_approve /admin/gestions/herencies/{uuid}/aprovar POST Aprova el traspàs successorori (registra SUCCESSION_CLAIM_APPROVED).
    app_admin_gestions_herencia_reject /admin/gestions/herencies/{uuid}/rebutjar POST Rebutja l'expedient (registra SUCCESSION_CLAIM_REJECTED).

    Aquest mòdul és el únic que pot accedir ROLE_GESTOR (equip de gestió d'herència) sense ser administrador. La decisió final és humana (Human-in-the-Loop); l'IA només aporta el retriatge documental. Vegeu sdd/09-herencia-digital.

    Serveis i supervisió (AdminSystemController) — 7 rutes¶

    Ruta Path Mètode Descripció
    app_admin_services /admin/serveis GET Estat dels serveis: cues Messenger (pendents/fallits per cua), GeoIP, connectors externs.
    app_admin_audit_logs /admin/logs GET Consulta de l'auditoria forense (registrals_audit; filtre per acció/usuari/period).
    app_admin_geoip_update /admin/serveis/geoip/update POST Actualitza la BD GeoLite2-Country local (equivalent a app:geoip:update).
    app_admin_messenger_retry /admin/serveis/messenger/retry/{id} POST Reintenta un missatger fallit concret.
    app_admin_messenger_retry_all /admin/serveis/messenger/retry-all POST Reintenta tots els missatgers fallits.
    app_admin_messenger_remove /admin/serveis/messenger/remove/{id} POST Elimina un missatger fallit (abandonat).
    app_admin_messenger_remove_all /admin/serveis/messenger/remove-all POST Elimina tots els missatgers fallits.

    Comandes equivalents (CLI)¶

    Acció al Backoffice Comanda equivalent
    Actualitzar GeoIP app:geoip:update
    Reintentar missatgers fallits messenger:failed:retry failed
    Eliminar missatger fallit messenger:failed:remove failed {id}
    Caducar traspassos > 72 h app:transfers:expire
    Reconciliar transaccions Stripe app:stripe:sync-sessions

    Regles de seguretat del Backoffice¶

    1. Rol exigit: ^/admin/gestions → ROLE_GESTOR; ^/admin → ROLE_ADMIN (la primera regla coincident guanya).
    2. CSRF: totes les rutes POST/GET,POST amb canvi d'estat inclouen token CSRF (tallafoc main amb enable_csrf: true).
    3. Auditoria: les accions administratives rellevants (toggle d'usuari, canvi d'estat de bé, reemborsament, gestions d'herència) es registren a registrals_audit.
    4. Profiler: l'accés al web profiler està guatat per ProfilerAccessGuardSubscriber (només en dev/test i per administradors).
