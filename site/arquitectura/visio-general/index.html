    Visió general de l'arquitectura¶

    Registrals és una aplicació Symfony 7.4 (PHP 8.3/8.4, tipat estricte) amb arquitectura hexagonal per a les integracions: el domini no coneix els proveïdors externs (Stripe, Polygon, Namirial, Signaturit, SGLang), sinó que treballa contra ports (interfícies) que els adaptadors d'infraestructura implementen.

    On viu cada cosa (mapa de directoris)¶

    Directori Responsabilitat
    src/Controller/ 40 controladors: pàgines públiques, àrea privada /app, backoffice /admin (subdirectori Admin/) i webhooks (subdirectori Webhook/).
    src/Entity/ 18 entitats Doctrine amb atributs natius i UUID v7 per a claus públiques.
    src/Enum/ 17 enums natius (estats de bé, certificat, traspàs, pagament, factura, KYC, herència…).
    src/Service/ 32 serveis de domini organitzats per àrea (Item/, Certificate/, Payment/, Invoice/, Transfer/, Legacy/, Security/, Storage/, Validation/, Plan/, Identity/, OAuth/, Blog/, GeoIp/).
    src/Repository/ 15 repositoris Doctrine amb consultes de negoci (CUI, quotes, sàfates de traspàs, factures…).
    src/Infrastructure/Adapter/ 5 parells port/adaptador per a integracions externes (Ai/, Blockchain/, Identity/, Payment/, Signature/).
    src/Security/ Tallafoc a mida: UserChecker, GoogleAuthenticator (OAuth2), LoginAuthenticationFailureHandler, exceptions de reptes OTP i Voter/ItemVoter.
    src/EventSubscriber/ 7 subscribers de nucli (Legal Gate, vida del bé, telemetria, reconeixement de dispositiu, reptes de seguretat, auditoria, guàrdia del profiler).
    src/Message/ + src/MessageHandler/ Missatgers i handlers de les cues asíncrones.
    src/Audit/ Subdomini d'auditoria forense amb connexió de BDD pròpia (App\Audit\Entity\UserActivityLog a registrals_audit).
    src/Form/ Formularis Symfony (alta de bé, perfil, administració…).
    src/Command/ 12 comandes de consola (seeders, operació, manteniment).
    src/Twig/ Extensions Twig propies (macros de plans, masking de privadesa…).
    templates/ 102 plantilles Twig (públiques, /app, /admin, certificats PDF, correus, partials).
    assets/ Fonts de Tailwind/JS compilades per l'AssetMapper a web/assets_build/.
    migrations/ 26 migracions versionades (MySQL 8.4, InnoDB, utf8mb4).
    web/ Arrel web (no public/): index.php, assets públics, manifest.json PWA, guia-destils.html.

    El flux d'una petició HTTP (síncrona)¶

    sequenceDiagram
  participant B as Navegador / PWA
  participant R as Runtime (web/index.php)
  participant FW as Tallafoc "main" (lazy)
  participant LG as LegalGateSubscriber (prioritat 0)
  participant C as Controlador
  participant S as Servei de domini
  participant D as Doctrine / Flysystem
  participant T as Twig (templates/)

  B->>R: GET /app/items/{cui}
  R->>R: Arrenca App\Kernel (env + debug)
  R->>FW: KernelEvents::REQUEST
  FW->>FW: Carrega usuari (email), rol, bloquejos (UserChecker)
  FW-->>LG: (si /app/* i clàusules no acceptades) → redirect /app/legal/acceptar-condicions
  LG-->>C: Request autoritzat
  C->>C: ItemVoter: canView? (propietari o ROLE_ADMIN)
  C->>S: Orquestració del cas d'ús
  S->>D: Lectura Item + documents (lazy ghost objects)
  S-->>C: Dades del cas
  C->>T: render('item/show.html.twig', ...)
  T-->>B: Resposta HTML PWA

    Punts clau d'aquest flux:

    1. Tallafoc lazy: la sessió/usuari no es carrega fins que una autorització ho demana (rendiment).
    2. Legal Gate s'executa després del tallafoc (prioritat 0 a KernelEvents::REQUEST) i només sobre /app/*: és la "quarta paret" lògica (vegeu Legal Gate i auditoria).
    3. Authorization objecte-a-objecte (voters) s'aplica al controlador o plantilla, mai en el router.
    4. Els fitxers custodiats mai es serveixen per URL directa: sempre a través de MediaController (guàrdia ItemVoter + StreamedResponse).

    El flux asíncron (cues)¶

    Per no bloquejar la petició, les operacions lentes o externes es deleguen a Symfony Messenger (persistit a MySQL):

    Missatger Cua Handler Què fa
    AnalyzeItemMediaMessage async_ai AnalyzeItemMediaMessageHandler OCR/visió local (Qwen VL via SGLang) de fotos i factures; desa aiMetadata i l'extracció forense.
    AnalyzeSuccessionClaimMessage async_ai AnalyzeSuccessionClaimMessageHandler Triage OCR local dels documents d'un expedient successorori (pre-aval per al ROLE_GESTOR).
    AnchorBlockchainMessage async_chain AnchorBlockchainMessageHandler Ancoratge criptogràfic del fingerprint SHA-256 a Polygon L2 (BlockchainReceipt).

    Detall complet a Cues i asíncronicitat.

    Ports i adaptadors (arquitectura hexagonal)¶

    El domini depèn mai d'una llibreria de terç per a les integracions. El mapping port → adaptador (tots registrats a config/services.yaml):

    Port (interfície) Adaptador Proveïdor Mode per defecte
    PaymentGatewayInterface StripeGatewayClient Stripe API Mock (sk_test_...mock) fins a claus reals
    SignaturitTimestampInterface SignaturitClient Signaturit (Grup Namirial) — TSP RFC 3161 Sandbox/aïllat fins a Fase II
    IdentityVerificationGatewayInterface NamirialOnboardingClient Namirial OnBoarding API v2 (eIDV) Entorn de test (Demo)
    BlockchainAnchorInterface PolygonAnchorClient Polygon PoS (JSON-RPC) Sandbox (txHash determinista) fins a Hot Wallet
    AiVisionAnalyzerInterface SglangVisionClient Node SGLang privat (Qwen VL) Node local; feature toggle AI_ASSISTANCE_ENABLED

    Aquesta separació permet: (a) testar el domini sense xarxa, (b) canviar de proveïdor (per exemple, en Fase II s'estan avaluant alternatives econòmiques de TSP/KYC), i (c) mantenir el mode mock per defecte en desenvolupament sense trencar el flux.

    Invariants d'arquitectura (regles de l'or)¶

    1. Immutabilitat i versionat: qualsevol canvi de dades o evidències d'un bé canvia el fingerprint SHA-256 → nova versió (Item::$version), nova línia a ItemHistoryLog i SUPERSEDED dels certificats vigents. (Vegeu el Bloc 2.)
    2. Custòdia privada: les fotos i proves viven fora de l'arrel web (Flysystem a var/data/registrals_storage) i es lliuren només amb autorització (MediaController + ItemVoter).
    3. Anclatge de hashs, mai de dades: a la blockchain només escriu el resum SHA-256 (calldata), mai fitxers. (Vegeu sdd/06c-polygon.)
    4. IA sobirana: el model de visió s'executa exclusivament al node privat (SGLang); mai no es mostren dades a tercers. La IA mai no "valida": només assisteix (Human-in-the-Loop, Art. 22 RGPD).
    5. Freemium anti-carrusel: alliberar capacitat (baixa/traspass) mai no retorna el pressupost d'altes anuals; els traspassos C2C al Pla Free costen 2,00 € per operació. (Vegeu AGENTS.md.)
    6. Terminologia: el terme «notarial» està prohibit a interfícies, còpia i documentació pública; s'usa «Garantia de Certificació», «Certificat», «Assistent de Custòdia»… (Vegeu AGENTS.md.)
