    Inici ràpid¶

    Guia per aixecar l'entorn de desenvolupament complet de Registrals des de zero: servidor web Symfony, base de dades MySQL 8.4 (Docker), asset pipeline (Tailwind) i consumers de cues.

    Prerequisits del sistema: PHP 8.3+ (el projecte fa servir tipat estricte i enums natius), Composer 2, Node.js 20+ (asset-mapper/Tailwind), Docker (MySQL 8.4) i un navegador recent per a la validació HITL a http://127.0.0.1:8004.

    1. Clonar i instal·lar dependències¶

    git clone <repo> Registrals
cd Registrals
composer install

    La carpeta web pública és web/ (no public/): el projecte reconfigura el directori públic mitjançant "public-dir": "web" a composer.json. El punt d'entrada és web/index.php, que utilitza Symfony Runtime (vendor/autoload_runtime.php) per arrencar el kernel App\Kernel.

    2. Configurar l'entorn (12-Factor)¶

    Copia .env a .env.local i ajusta-hi els valors locals. Les variables completes (34) estan documentades a Kernel i configuració → Variables d'entorn. Les crítics per al primer arrencada:

    Variable Valor típic DEV On s'usa
    APP_ENV / APP_DEBUG dev / 1 Nucli Symfony
    APP_SECRET (genera'n un aleatori) Signatura de galetes/sessions
    DATABASE_URL mysql://app:%21ChangeMe%21@127.0.0.1:3306/registrals?serverVersion=8.4&charset=utf8mb4 Connexió principal (Doctrine default)
    AUDIT_DATABASE_URL mysql://app:%21ChangeMe%21@127.0.0.1:3306/registrals_audit?serverVersion=8.4&charset=utf8mb4 Connexió d'auditoria forense (Doctrine audit)
    MESSENGER_TRANSPORT_DSN doctrine://default Cua principal async
    MAILER_DSN null://null (o Mailpit: smtp://127.0.0.1:1025) Correu transaccional 12-Factor
    STRIPE_SECRET_KEY sk_test_registrals_mock (mode mock per defecte) Passarel·la de pagament
    BLOCKCHAIN_RPC_URL / BLOCKCHAIN_NETWORK Node RPC de Polygon / amoy Ancoratge criptogràfic
    SGLANG_API_BASE_URL http://127.0.0.1:30000/v1 (o el node privat) Assistència IA sobirana (Qwen VL)

    3. Base de dades (Docker)¶

    El projecte fa servir MySQL 8.4 en contenidor Docker (servei database a compose.yaml), muntat per defecte a 127.0.0.1:3306 amb la base de dades registrals i l'usuari app (password !ChangeMe!):

    docker compose up -d

    Importa que existisquen dues bases de dades (dues connexions Doctrine, vegeu Kernel i configuració):

    CREATE DATABASE IF NOT EXISTS registrals CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE IF NOT EXISTS registrals_audit CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

    4. Migracions i seeders¶

    Les migracions versionades (26 fitxers a migrations/) creen l'esquema complet. Executa-les sobre ambdues connexions:

    bin/console doctrine:migrations:migrate --em=default
bin/console doctrine:migrations:migrate --em=audit

    Després pobla les dades de referència:

    bin/console app:init-plans          # Plans Free / Plus / Unlimited (sense esmocar valors en viu si no passes --force-reset)
bin/console app:init-categories     # Categories i subcategories base B2C/C2C

    Valida l'esquema sincronitzat:

    bin/console doctrine:schema:validate

    5. Servidor web¶

    L'aplicació es serva a http://127.0.0.1:8004 (port institucional del projecte):

    bin/console server:run 127.0.0.1:8004

    Comprovacions mínimes:

    • http://127.0.0.1:8004/ → Landing corporativa.
    • http://127.0.0.1:8004/login → Formulari de login.
    • http://127.0.0.1:8004/guia-destils.html → Guia d'estils viva.

    6. Asset pipeline (Tailwind + AssetMapper)¶

    Els estils viuen a assets/ (Tailwind CSS + JS) i es compilen a web/assets_build/ mitjançant AssetMapper (estrict en dev, warn en prod):

    npm install
npm run dev      # build incremental amb hot-reload (process resident)
# o bé, build òptim:
npm run build

    7. Consumers de cues (assíncron)¶

    L'aplicació envia missatges a tres cues persistides a MySQL (taula messenger_messages): async_ai (anàlisi IA), async_chain (ancoratge Polygon) i failed (incidències). En desenvolupament, consumeix-los en un terminal separat:

    bin/console messenger:consume async_ai async_chain -vv

    Per a detalls de transports, estratègies de reintent i monitorització al Backoffice, vegeu Cues i asíncronicitat.

    8. Comandes de manteniment i operació¶

    Registre complet de les 12 comandes de l'aplicació (bin/console list app:):

    Comanda Finalitat
    app:init-plans Pobla/actualitza els plans Free, Plus i Unlimited.
    app:init-categories Pobla/actualitza les categories i subcategories base.
    app:user:create-admin Crea un usuari administrador dedicat (ROLE_ADMIN).
    app:user:promote-admin Promou un usuari existent a ROLE_ADMIN.
    app:user:reset-password Restableix la contrasenya d'un usuari existent.
    app:item:anchor-blockchain Notarització criptogràfica manual/síncrona d'un bé a Polygon.
    app:transfers:expire Caduca els traspassos C2C pendents > 72 h (també via cron).
    app:certificates:regenerate-drafts Regenera els PDFs dels certificats esborrany.
    app:stripe:sync-sessions Reconciliació de transaccions pendents de Stripe (doble capa de seguretat).
    app:geoip:update Actualitza la base GeoLite2-Country local (MaxMind).
    app:kyc:test Sessió de prova contra Namirial OnBoarding API v2.
    app:blog:pretranslate Pretradueix els articles del blog a ES/EN (memòria cau per hash SHA-256).

    9. Prova de codi¶

    Bateria PHPUnit (100% del nucli cobert pels tests unitaris i funcionals descrits al full de ruta):

    vendor/bin/phpunit

    L'entorn test utilitza sessions de fitxers simulats (mock_file), cost d'hash reduït (cost: 4) i strict_variables: true a Twig (vegeu Kernel i configuració).

    Solució de problemes habituals¶

    Sintoma Causa probable Solució
    Connection refused a MySQL Contenidor no aixecat docker compose ps i docker compose up -d
    An exception occurred while iterating / cache antic Cache de kernel antic bin/console cache:clear
    El CSS no es veu AssetMapper sense build npm run build
    Els missatges no es procesen Cap consumer actiu Llança messenger:consume async_ai async_chain
    Class "App\Entity\..." not found Autoloader desactualitzat composer dump-autoload
    Webhooks de Stripe no funcionen Sense túnel públic Utilitza stripe listen --forward-to 127.0.0.1:8004/webhook/stripe (test mode)
