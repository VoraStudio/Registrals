1 Stripe: Pagaments, Subscripcions & Facturació

SDK Oficial PHP v16+
1.1. Arquitectura de Cobrament Dual
Hosted Checkout

Registrals utilitza el servei Stripe Checkout en mode allotjat per complir l'estàndard PCI-DSS SAQ A i donar suport natiu a Apple Pay, Google Pay i 3D Secure 2.0 sense gestionar dades de targetes al nostre servidor.

Mode Subscripció (Anual)

Utilitzat per als plans Plus (22 €/any) i Unlimited (59 €/any).
Paràmetre: mode => 'subscription'.
Genera objectes Subscription i vincula customer_id permanent a l'usuari.

Mode Pagament Solt (Pay-per-Value)

Utilitzat per a Certificats oficials solts (5,90 €) o traspassos C2C solts (2,90 €).
Paràmetre: mode => 'payment'.
Genera objecte PaymentIntent immediat.

Regla d'Or d'Enginyeria: Mai aprovar ni activar un pla o servei a la pàgina de retorn success_url. Si l'usuari tanca la pestanya abans de la redirecció, el cobrament existiria a Stripe però no a la base de dades. Tota activació es fa exclusivament al Webhook criptogràfic.

'?session_id={CHECKOUT_SESSION_ID}', 'cancel_url' => $this->generateUrl('app_plan', [], UrlGeneratorInterface::ABSOLUTE_URL), ]); return new RedirectResponse($session->url); }

HMAC-SHA256 Signature

2 Signaturit: Segellat de Temps eIDAS & Identitat eIDV

eIDAS QTSP Qualified
2.1. Segellat de Temps Qualificat (TSP / RFC 3161)
Art. 41 Reglament UE 910/2014

Com a Prestador Qualificat de Serveis de Confiança (QTSP) acreditat davant la UE, Signaturit atorga presumpció legal d'exactitud de data i hora davant tribunals de justícia i companyies asseguradores.

Privadesa per Disseny (Art. 25 RGPD): Registrals mai envia el document PDF ni dades personals a Signaturit. Només es transmet el hash criptogràfic SHA-256 de 32 bytes del document. Signaturit segella el hash i emet el certificat d'auditoria X.509 sense conèixer mai el contingut.
Payload HTTP enviat a https://api.signaturit.com/v3/timestamps.json JSON Payload
{ "hash": "a8f5b61c92d04e38e1b4c910385920a4b7c891e23f0485910294857102938475", "hash_algorithm": "SHA256" }
2.2. Verificació d'Identitat Biomètrica (eIDV / KYC)
Anti-Deepfake & Liveness Detection

Flux d'identificació digital per al reconeixement de titulars oficials i certificats d'alta gamma:

1. Captura Documental

OCR de DNI, NIE o Passaport (>200 països) amb comprovació de patrons hologràfics i línies MRZ.

2. Biometria Facial

Selfie en temps real amb liveness detection i comparativa facial 1:1 contra la foto del document.

3. Traçabilitat Forense

Recepció de veredicte de validació i certificat d'auditoria custodiat a Flysystem privat.

3.2. Estructura de Calldata d'Ancoratge Determinista
0x52454749 (REGI Prefix)

Per mantenir el cost marginal per sota de 0,003 € sense desplegar contractes complexos de gas elevat, Registrals grava el hash a les dades d'entrada (Calldata) de la transacció:

Estructura del Calldata a Polygonscan Format Hexadecimal
// Format: 0x52454749 [CodiAcció: 2 caràcters] [CUI: 20 caràcters] [HashSHA256: 64 caràcters] 0x52454749014355492d3230323631303331303031a8f5b61c92d04e38e1b4c910385920a4b7c891e23f0485910294857102938475 // 0x52454749 = ASCII per "REGI" // 01 = ITEM_REGISTRATION (02 = TRANSFER, 03 = STOLEN, 04 = CERTIFICATE) // Resta = CUI del bé moble + Hash SHA-256 mestre certificat
Processament Asíncron: La transacció a Polygon PoS triga entre 2 i 3 segons a minar-se. Mitjançant Symfony Messenger (cua async_chain), la interfície d'usuari respon immediatament i el worker en segon pla signa la transacció i emmagatzema l'entitat BlockchainReceipt.

5 Protocols d'Idempotència i Resiliència Davant Caigudes

Alta Disponibilitat
Stripe: Idempotència

Els event.id de webhook es registren a una taula d'auditoria. Si Stripe repeteix la notificació per retard de xarxa, rep un 200 OK instantani sense duplicar càrrecs ni transaccions.

Signaturit: Timeout Safe

Si el servidor de signatura triga més de 10 segons o retorna error 5xx, l'emissió del certificat no es perd: es marca en reintent asíncron (retry_pending) o s'activa el simulador segur en DEV.

Polygon: Backoff Exponencial

Si el node RPC pateix congestió, Symfony Messenger reintenta l'enviament fins a 5 vegades amb intervals exponencials abans d'enviar el missatge a la cua failed de l'Admin.

Com donar-se d'alta a Stripe
  1. Crear compte a stripe.com.
  2. Accés instantani a Sandbox (claus pk_test/sk_test).
  3. Per a Live: NIF/CIF fiscal, DNI de l'administrador i IBAN bancari (validat en 24-48h).
  4. Configurar Webhook a /webhook/stripe.
Com donar-se d'alta a Signaturit
  1. Compte de desenvolupador a signaturit.com.
  2. Generació de token Sandbox per a tests.
  3. Contractació de paquet de segellats TSP eIDAS i crides eIDV amb l'equip de vendes.
  4. Configuració de token Live a SIGNATURIT_API_TOKEN.
Com operar a Polygon PoS
  1. Sense registre ni censura (xarxa descentralitzada).
  2. Generar clau privada EVM i desar a .env.local.
  3. Crear compte gratuït a Alchemy per a node RPC dedicat.
  4. Ingressar 20 € en token POL (dona per a > 7.000 notaritzacions).

7 Anàlisi d'Alternatives Tecnològiques i Criteris de Decisió

Benchmarking de Mercat

7.1. Alternatives a Stripe (Passarel·la de Pagaments)

Stripe (Solució Oficial Triada)
Opció Oficial d'Entrada

L'estàndard mundial indiscutible en desenvolupament de programari: Hosted Checkout d'alta conversió, suport d'Apple Pay / Google Pay nadiu, Customer Portal automatitzat i gestió de subscripcions sense fricció.

Trade-off: Comissió del 1,5% + 0,25 € lleugerament superior a la banca tradicional, àmpliament compensada per l'estalvi d'hores de desenvolupament i la conversió mòbil.
Redsýs / TPV Virtual Bancari (CaixaBank, Santander, BBVA)
Candidat Futur per a Escala Nacional

Comissions molt inferiors (~0,3% a 0,5%) i compatibilitat directa amb Bizum a Espanya.

Trade-off: UX fragmentada amb redireccions feixugues del banc, gestió de subscripcions recurrents complexa i manual, sense Customer Portal. Recomanable quan Registrals superi els 100.000 € anuals de facturació per estalviar costos de comissió.
Paddle / Lemon Squeezy (Merchant of Record)
Descartat

Comissió abusiva (5% + 0,50 $ per càrrec) que fa inviables els microtransaccions de 2,90 € (deixaria més d'un 25% en comissions).

7.2. Alternatives a Signaturit (Segellat eIDAS & KYC)

Signaturit Group (Solució Oficial Triada)
Opció Oficial d'Entrada

QTSP acreditat davant la UE. Unifica en una sola plataforma el segellat de temps qualificat legal (TSP) i la verificació documental/biomètrica (eIDV).

Validated ID (VIDsigner)
Pla B Directe de Redundància

Proveïdor qualificat eIDAS amb seu a Barcelona, d'excel·lent reputació tècnica i jurídica. És el nostre candidat immediat de substitució o redundància si fos necessari.

FNMT (Fábrica Nacional de Moneda y Timbre) / Camerfirma
Alternativa Institucional

Màxim reconeixement estatal, però alta i contractació feixugues, burocràtiques i allunyades del model àgil SaaS.

7.3. Alternatives a Polygon PoS (Blockchain)

Polygon PoS (Solució Oficial Triada)
Opció Oficial d'Entrada

Temps de bloc de 2 segons, cost de transacció < 0,003 €, totalment compatible amb EVM i màxim suport d'eines d'auditoria pública (Polygonscan).

Base (Layer 2 de Coinbase)
Millor Alternativa L2

Optimistic Rollup d'Ethereum recolzat per Coinbase. Comissions de fracció de cèntim gràcies a l'EIP-4844 d'Ethereum. Commutable fàcilment des del nostre port BlockchainAnchorInterface.

Ethereum Mainnet (Layer 1)
Descartat per a Ancoratges Individuals

Cost de gas d'entre 1 € i 15 € per transacció. Totalment incompatible amb el model Freemium i les microtransaccions.
